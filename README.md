#  Orbit Tasks

A modern and interactive **Kanban Task Manager** built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS 4**, and **Dnd Kit**.

Orbit Tasks simulates a real-world project management application focused on productivity, reusable architecture, drag-and-drop interactions, persistent data, and modern UI/UX practices.


## Live Demo
https://orbit-tasks-ten.vercel.app/

# Features

### Task Management

* Create new tasks
* Delete tasks
* Multiple Kanban columns
* Task priorities
* Due dates
* Tags
* Team members

### Drag & Drop

* Drag tasks inside the same column
* Drag tasks between columns
* Smooth Drag Overlay
* Keyboard accessibility
* Powered by Dnd Kit

### Dashboard

* Dynamic task statistics
* Completed tasks
* Remaining tasks
* Progress indicator
* Real-time updates

### Persistence

* LocalStorage persistence
* Automatic state restoration

### UI

* Dark Mode
* Responsive Layout
* Smooth animations
* Clean component architecture

### Technical

* React Context API
* React Hook Form
* TypeScript
* Next.js App Router
* SEO Metadata
* Sitemap
* Robots
* Web Manifest

#  Getting started

Clone the repository

```bash
git clone https://github.com/wwilliamsantana/orbit-tasks.git
```

Navigate into the project

```bash
cd orbit-tasks
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```text
http://localhost:3000
```



#  Production Build

```bash
npm run build
npm run start
```
